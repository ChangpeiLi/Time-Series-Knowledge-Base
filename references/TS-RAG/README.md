# TS-RAG

## Paper
Time Series Retrieval-Augmented Generation

## Role in this project
TS-RAG provides the time-series retrieval pipeline that will be studied and adapted for constructing an external time-series knowledge base.

## Key parts to study

- Time-series slicing
- Time-series encoder
- Projection from raw numerical series to embeddings
- Knowledge base construction and storage
- Similarity calculation
- Retrieval and Top-K recall
