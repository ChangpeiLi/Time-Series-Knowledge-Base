# Time-Series-Knowledge-Base

A knowledge base for time-series forecasting, time-series retrieval, and time-series question answering.

This repository focuses on two core reference methods:

- TS-RAG
- ChatTS

It also collects important electricity and energy time-series datasets used in related research.
