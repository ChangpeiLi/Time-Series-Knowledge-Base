# Electricity / Energy Time-Series Datasets

This folder collects electricity- and energy-related time-series datasets used in the papers studied in this project.

## Datasets

### ETT
- ETTh1
- ETTh2
- ETTm1
- ETTm2

### Electricity / ECL
- Electricity Load Diagrams dataset

### Solar-Energy
- Solar power generation dataset

## Information to Collect

For each dataset:

- Dataset name
- Related papers
- Data source
- Number of variables
- Sampling frequency
- Time span
- Dataset format
- Forecasting task
- Official download link
- Whether the raw data is stored in this repository
