# Solar-Energy Dataset

## Basic Information

- Dataset name: Solar-Energy
- Domain: Solar power generation
- Number of variables: 137
- Sampling frequency: 10 minutes
- Task: Multivariate time-series forecasting

## Description

Solar-Energy is a multivariate time-series dataset containing solar power production records from 137 photovoltaic plants.

It is commonly used as a benchmark dataset for long-term time-series forecasting.

## Data Storage

The raw dataset will be stored directly in this repository if the file size is suitable for GitHub.

If the file is too large, only the official download source and instructions will be provided here.

## Usage in This Project

This dataset can be used as a real-world energy dataset for evaluating time-series understanding and retrieval-augmented methods.
