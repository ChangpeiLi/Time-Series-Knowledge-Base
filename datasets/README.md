# Datasets

This folder contains datasets related to the time-series knowledge base and experimental evaluation.

The datasets are divided into two categories:

## Synthetic Datasets

Synthetic time-series data generated with controlled attributes, such as:

- Trend
- Periodicity
- Noise
- Upward / downward spikes
- Continuous anomalies
- Local changes

These datasets can be used to evaluate whether the model correctly understands known time-series patterns and anomalies.

## Real-World Datasets

Real-world time-series datasets collected from practical domains.

The current focus includes:

- Electricity / Energy
- Weather
- Traffic

For each dataset, the following information will be recorded:

- Dataset name
- Data source
- Related paper
- Number of variables
- Sampling frequency
- Dataset size
- Download link
- Usage in the project
