# Synthetic Time-Series Datasets

This folder is used to organize synthetic time-series data generated by ChatTS.

## Generation Source

The synthetic data is mainly generated by:

- `chatts/ts_generator/generate.py`
- `chatts/sft/generate_llm_qa.py`

## Main Characteristics

The generated time series may contain:

- Trend
- Periodicity
- Noise
- Upward spike
- Downward spike
- Continuous upward spike
- Continuous downward spike
- Sudden increase / decrease
- Other local changes

## Generation Pipeline

Attribute Configuration
→ Attribute Pool
→ Synthetic Numerical Time Series
→ Attribute Description
→ Prompt Construction
→ LLM-generated Question-Answer Pairs

## Usage in This Project

Synthetic datasets will be used to test whether ChatTS and the retrieval-augmented ChatTS can correctly identify known time-series patterns, especially under noise and continuous anomaly scenarios.
